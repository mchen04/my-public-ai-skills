# Red-team

Track concrete defects to terminal states. Use a separately scoped research task for comparative choices. Freeze scope and a known-defect fail-demo. Choose the smallest adequate set of attacker, insider, admin, malicious-content, limit/race, skeptic and functional lenses. Rotate them between cycles.

Prefer reproduced counterexamples. Use blind refutation for interpretive/high-impact model-only claims; no model vote can override an executed failure. Each row needs location, severity, mechanism, state and evidence. Close as fixed+verified (observed or better), not-reproducible (refuting evidence), or external-blocker (named missing access/setup). No silent backlog or suppression.

## Read-only mode

For forensic/data/financial audits make no writes. Use database READ ONLY transactions. Compare goal, UI, API and database; agreement among implementation layers can still contradict the goal.

Emit `VERDICT: PASS` only with no open in-scope finding, otherwise `VERDICT: FAIL`. One audit is one pass; repeated convergence binds this charter as loop CHECK.
