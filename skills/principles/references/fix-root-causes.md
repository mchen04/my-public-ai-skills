# fix-root-causes

- Capture a repro with the input and observed result.
- Separate work defects from harness and environment failures.
- Trace backward to the first value or decision that became wrong.
- After two failed repairs sharing a premise, test that premise directly.

Owners: [fix-bug](../../fix-bug/SKILL.md), [project-verification](../../project-verification/SKILL.md), [believe](../../believe/SKILL.md).
Enforcement: Prose only for causal diagnosis; the project’s repro and regression check enforce the specific repair.
