# subtract-before-you-add

- Read the existing destination before adding another rule.
- Compare the current variant with one suspected redundancy removed.
- Retain helpers, preferences and safeguards unless evidence supports their removal.
- Keep the smaller variant only when required outcomes survive.

Owners: [skill-maintenance](../../skill-maintenance/SKILL.md), [eval-hillclimb](../../eval-hillclimb/SKILL.md).
Enforcement: blind comparisons test behavioral retention.
