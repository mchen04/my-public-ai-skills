# own-only-your-changes

- Record dirty paths before beginning implementation.
- Keep a live writer’s checkout under that writer’s control.
- Restore planted probes file by file from retained original text.
- Use the branch artifact sweep before a deliverable commit.

Owners: [open-pr artifact sweep](../../open-pr/SKILL.md#process), [safe-push](../../safe-push/SKILL.md).
Enforcement: Inspect dirty paths and use isolated checkouts. The public package does not enforce ownership across separate agent processes.
