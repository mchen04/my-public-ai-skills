# answer-by-experiment

- Classify the unknown as observable behavior or a user preference.
- Choose the smallest authorized probe that distinguishes the alternatives.
- Run it against synthetic state when the workflow requires isolation.
- Report the observation and ask only the product choice that remains.

Owners: [project-verification](../../project-verification/SKILL.md), [eval-hillclimb](../../eval-hillclimb/SKILL.md).
Enforcement: Prose only for choosing a useful experiment; the selected probe supplies its own executable evidence.

Adopted from [pstack](https://github.com/cursor/plugins/tree/main/pstack).
