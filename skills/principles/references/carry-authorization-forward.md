# carry-authorization-forward

- Name the exact action and the user authorization that covers it.
- Finish authorized previews and reversible preparation.
- Keep destructive, credential and publication gates in the acting workflow.
- Give every question or decision that waits on the user the default you will apply if they do not
  answer. Apply that default and continue. At a gate, the default is to not act.
- When a gate really stops progress, cite its rule and the missing decision.

Owners: [safe-push](../../safe-push/SKILL.md), [release](../../release/SKILL.md), [open-pr](../../open-pr/SKILL.md).
Enforcement: Prose only for interpreting user authority; workflow helpers enforce their narrower action boundaries.
